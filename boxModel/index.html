Contéudo Principal

Por padrão em alguns elementos são block e em outros são inline.

Exemplo de elementos block: , p, h1, h2, h3, h4, h5, h6, ul, ol, li

Exemplo de elementos inline: span, a, strong, em

Os elementos block ocupam toda a largura disponível do elemento pai, enquanto os elementos inline não.
