O que é o Cinema Origamid?

O Cinema Origamid é um projeto fictício criado para fins educacionais. Ele visa fornecer informações sobre cinemas em diferentes cidades do Brasil, como São Paulo e Rio de Janeiro.

Este projeto é parte de um curso de desenvolvimento web e tem como objetivo ensinar conceitos de HTML, CSS e JavaScript, além de práticas de design e usabilidade.
