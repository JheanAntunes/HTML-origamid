Clique Aqui
  1. O elemento :hover é ativado quando o mouse passa sobre o elemento.
  2. O elemento :focus é ativado quando o elemento recebe foco, como ao clicar em um campo de formulário.
  3. O elemento :active é ativado quando o elemento está sendo clicado.
  4. O elemento :disabled é ativado quando o elemento está desativado.
  5. O elemento :visited é ativado quando o elemento foi visitado.
